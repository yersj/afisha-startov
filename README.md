# Афиша стартов

Календарь беговых стартов: марафоны, полумарафоны, серия TAN.

## Как добавить или изменить старт

Все старты лежат в файле `races.json`. Откройте его на GitHub, нажмите ✏️ и добавьте блок:

```json
{
  "id": "almaty-marathon-2027",
  "title": "Almaty Marathon 2027",
  "date": "2027-09-26",
  "time": "07:00",
  "city": "Алматы",
  "country": "Казахстан",
  "distances": [42.2, 21.1, 10],
  "kind": "Шоссе",
  "series": "TAN",
  "url": "https://...",
  "tentative": true,
  "runners": "Айдар (42.2), Мадина (10)",
  "note": "Сбор клуба у шатра в 6:45"
}
```

Обязательны только `id`, `title` и `date` (в формате ГГГГ-ММ-ДД). `tentative: true` показывает пометку «Дата уточняется». После сохранения сайт обновится через 1–2 минуты.
